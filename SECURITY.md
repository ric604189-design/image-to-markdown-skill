# Security Policy

## Supported versions

Security fixes are applied to the latest main branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or credential exposure.
Use GitHub private vulnerability reporting for this repository. If it is not
available, contact the repository owner privately through GitHub.

Include the affected revision, safe reproduction steps, impact, and any
mitigation. Do not attach real API keys, private images, PDFs, or OCR output.
